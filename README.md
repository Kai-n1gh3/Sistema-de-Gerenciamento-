Sistema de Gerenciamento de Funcionários e Folha de Pagamento

Aplicação Java desenvolvida com Programação Orientada a Objetos (POO), arquitetura em camadas, tratamento de exceções personalizadas e Desenvolvimento Orientado a Testes (TDD) com JUnit 5.

Contém:
- Cadastro de Funcionários
- Listagem de todos funcionários
- Busca de funcionário por código identificador, CPF ou nome
- Remoção de funcionário cadastrado
- Cálculo individual de remuneração e tributps
- Exibição dos dados completos de um colaborador
- Relatório folha pagamento
- Cálculo do total da folha de pagamento da empresa

A separação do código foi feita em camadas, com armazenamento em memória.

(Única exceção é não ter os comitts)
